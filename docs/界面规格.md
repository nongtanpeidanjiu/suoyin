# 界面规格 v5.0

状态：已获用户同意的设计方向（2026-11-18）。界面层由统筹方实现，搜索核心不负责界面。

软件名称：索隐（商标尚未核实）。界面上称呼本软件时一律用“索隐”（“关于索隐”、“欢迎使用索隐”、菜单栏图标的提示和读屏标签）；预览版在访达、系统设置和“关于”窗口里显示为“索隐（预览）”。只改给人看的名字：包标识 `dev.local.filesearch.demo`、预览版安装位置 `~/Applications/文件搜索预览.app`、数据目录、偏好设置键、分布式通知名、签名证书名和可执行文件名 `SearchApp` 保持不变，改了会让已授予的完整磁盘访问权限失效。

## 1. 设计原则

- 用系统自带的东西：系统字体、SF Symbols、系统强调色、毛玻璃材质、真实文件图标。自动跟随浅色和深色模式。
- 只用一种强调色（系统强调色）。不用渐变、发光、彩色光晕、星形装饰。
- 输入即出结果的手感优先于一切动画：与按键直接相关的反馈不加动画。
- 尊重系统辅助功能设置：减少动态效果、增强对比度、读屏（每个控件有无障碍标签）。
- 所有界面文字走本地化表，首批中文和英文。

## 2. 入口

| 入口 | 行为 |
|---|---|
| 菜单栏图标左键 | 切换搜索面板的显示和隐藏 |
| 菜单栏图标右键或按住 Control 点击 | 弹出菜单：打开搜索、索引状态、无法访问的位置、设置、退出 |
| 全局快捷键（默认 Option + Shift + 空格，可改） | 与左键相同 |
| 程序坞 | 默认不显示图标（常驻菜单栏类应用），设置里可改 |

菜单栏图标是单色模板图，随菜单栏深浅自动变色。三种状态：平时（放大镜内两条短线）、建索引中（外圈缺口缓慢旋转）、需要处理（放大镜内感叹号）。

## 3. 搜索面板

设计参照：苹果在 macOS 26 中重新设计的系统搜索（聚焦搜索）。本软件不照搬其功能，只沿用它的形态语言。

形态：一块明亮通透的玻璃，跟随系统的浅色和深色模式。宽 640。

- 静止时是一枚胶囊：只有一行搜索框，高 54，两端是完整的半圆（圆角 27）。
- 开始输入后，同一块玻璃向下生长，依次出现筛选行和结果列表；圆角保持 27，搜索行本身不移动。
- 面板出现在当前屏幕水平居中、搜索行位于屏幕高度约三分之一处。屏幕较矮时整体上移，保证完整列表放得下。
- 失去焦点或按 Esc 时收起。可以拖动。
- 玻璃上覆一层很淡的白（深色模式为淡黑），边缘有一条亮的细线作为玻璃的高光；使用系统窗口阴影。

结构自上而下：

1. 搜索行（高 54）：放大镜符号、输入框（23 号字，占位文字“搜索文件”）。
2. 筛选行（高 34）：左侧是胶囊形筛选按钮“名称”“路径”（搜索范围），当前项底色略深，点击或按 Tab 切换。隔开 14 点后是类型筛选胶囊，右侧用很淡的小字显示结果数量或索引状态。
   - 类型筛选是一枚带小下箭头的胶囊，与范围按钮同一套样式。不限类型时写“类型”，底色与未选中的按钮相同；选了某一类后改写该类名称（如“图片”），底色加深，一眼可知正在筛选。点按后在胶囊下方弹出菜单：不限、（分隔线）文件夹、文稿、图片、音频、视频、压缩包、应用程序，每项带 SF Symbols 图标、当前项打勾、右侧标出快捷键 ⌘1 至 ⌘8。
   - 选这个形式而不是八个并排的胶囊或一排纯图标：640 宽放不下十个胶囊，纯图标要靠悬停才认得出；一枚胶囊既不挤，又直接写出当前类型。
   - 切换类型后结果立即刷新，面板高度随结果数伸缩；没有结果时显示“没有找到匹配的文件”。每次打开面板都从“不限”开始（收起时记下的类型不保留），避免用户忘了上次选过类型而以为搜不到。“名称/路径”的选择照旧保留。
   - 判定规则以核心为准（`docs/里程碑4-门面验收.md`）：文件夹含应用程序包和文稿包；其余按文件名最后一个扩展名，不读正文。
   - 右侧状态文字用等宽数字字体，数字每半秒变化时不跳动；放不下时只从中间省略来源名称，结果数和已收录数量始终完整。
3. 结果列表：每行高 46。左侧真实文件图标（30），第一行文件名（14 号，匹配部分只加粗、不变色），第二行所在位置（11.5 号，次级颜色，用“›”分隔）。文件名和所在位置都始终只占一行，放不下时从中间省略，保留开头和结尾（文件名因此总能看到扩展名），省略后加粗照旧；即使是没有空格的超长名字（如一串百分号编码）也不会折成两行压住下一行，右侧修改时间（今天显示时刻，今年显示月日，更早显示完整日期）。云端未下载的文件名后加云朵符号，外接盘上的加外接盘符号。
4. 选中行：一块圆角的半透明灰色底，不使用强调色，文字颜色不变。整个面板的颜色只来自文件图标。
5. 没有底栏。快捷键说明放在设置和首次引导里。

尺寸变化：最多显示 7 行半（露出半行提示可以滚动），不足按实际行数。没有结果时显示一行“没有找到匹配的文件”。

查询文字：发给核心的查询和结果高亮用的分词，会先把所有 Unicode 空白（不换行空格、全角空格、U+2002 至 U+200A 各种宽度的空格、零宽空格等）统一换成普通空格，因此 Option + 空格误输入的不换行空格同样起分词作用，不会导致搜不到。输入框里显示的文字保持用户输入的原样。

预览的位置：快速查看打开时停靠在搜索面板右侧，方便边换行边看列表。

- 当前屏幕可见区宽度放得下“面板 640 + 间距 12 + 预览 560”且两侧各留至少 24 时：面板平滑左移，使面板和预览这一组在屏幕水平居中；预览宽 560，在面板右侧 12 处，上沿与面板上沿对齐，高度与面板当前高度一致，但不小于 360（面板只有一两行时），也不超出屏幕可见区底部。用户拖动过面板时，面板尽量留在原处，只在预览会超出屏幕右侧时才向左让开。
- 预览打开期间面板因结果数变化而伸缩，预览高度逐帧跟随，上沿保持对齐；上下方向键换文件时预览窗口位置和尺寸不变（系统按内容自行调整窗口时，会在同一帧内放回停靠位置）。
- 停靠时预览原地淡入淡出，不从结果行放大出来、也不缩回结果行。
- 预览关闭时面板平滑移回原位：用户没拖过就是居中位置，拖过就是最后放下的位置。预览打开期间拖动面板，预览跟着停在面板右侧，关闭后面板留在拖到的地方。面板自己的移动不算作用户拖动。
- 屏幕不够宽（如外接竖屏）时不移动面板，预览按系统默认位置出现，并从选中行放大出来。

预览的内容：凡是内容本质上是文字的文件，预览都显示内容，不只显示一个大图标。

- 系统快速查看自己能预览的类型一律交给系统，效果不变：图片、PDF、音视频、Office 文稿和表格、网页、CSV、纯文本和各种源代码（txt、log、diff、sh、py、swift、js 等）、JSON、XML、属性列表、RTF、名片、日历、邮件等。系统纯文本预览能自己识别 UTF-8、UTF-16 和国标（GB18030/GBK）编码的中文。
- 系统只给图标的文字文件（如 Markdown、YAML、TOML、ini、conf、sql、srt、css、以点开头的配置文件，以及被系统误认成视频的 TypeScript `.ts`），先读文件开头 64 KB 判断是不是文字：是合法的 UTF-8、带字节序标记的 UTF-16，或国标编码中文，且不含空字符、控制字符不超过百分之一，就当文字。判断在后台进行，不卡界面；结果出来前先显示系统的通用视图，出来后原地换成内容。快速切换选中行时，过期的判断结果直接丢弃。
- 换成内容的做法：在本应用的缓存目录（`~/Library/Caches/<应用标识>/PreviewStandIns`）里放一个替身，文件名是“原文件名.txt”，预览标题仍显示原文件名。2 MB 以内的 UTF-8/UTF-16 文件用 APFS 克隆生成替身，不占额外空间；不能克隆（跨卷）、超过 2 MB 或国标编码的，把开头 2 MB 转成 UTF-8 写入替身，超过时末尾注明“（文件较大，仅显示开头部分）”。系统不跟随符号链接（会显示链接本身的图标），所以不用符号链接。
- Markdown（512 KB 以内）用系统自带的 Markdown 解析渲染成网页：标题层级、列表、代码块、引用、表格（含对齐和空单元格）、粗体斜体删除线都按样式显示，跟随浅色和深色模式；文件开头的 YAML 头信息原样放在灰框里；内嵌的 HTML 只当文字显示，不执行，也不加载任何图片、链接或外部资源。解析失败或超过 512 KB 时按纯文本显示。
- 原文件只读不写，替身只放在缓存目录。缓存只保留当前和上一个文件的替身，预览关闭时全部删除，启动时也清理一次残留。
- 替身装着用户文件的内容，所以只有当前用户能读写：`PreviewStandIns` 及其中每个子目录权限为 0700（已存在的旧目录也会改成 0700），替身文件为 0600。写入的替身一创建就是 0600；克隆出的替身会继承原文件的权限，克隆后立即改为 0600（只改替身，原文件不受影响）。
- 压缩包、应用程序、文件夹、二进制文件、空文件保持系统通用视图。文件已不存在或读不到时显示系统自带的提示。
- 已知局限：用替身显示时，快速查看右上角的“用某应用打开”针对的是替身（Markdown 会提示用浏览器打开），不是原文件；打开原文件请用回车。

## 4. 键盘和鼠标

| 操作 | 结果 |
|---|---|
| 上下方向键 | 移动选中行，焦点仍在输入框 |
| 回车或双击 | 打开文件 |
| Command + 回车 | 在访达中显示 |
| 预览快捷键（默认 Option + 空格，可在设置里更改）或 Command + Y（固定的备用键，不能更改），有选中行时 | 用系统的快速查看预览选中的文件；再按一次、按 Esc 或在预览里按空格关闭。单独的空格始终是输入的空格（空格是分词符，不能另作他用）；预览快捷键只在面板是当前窗口时生效，不注册成全局快捷键；按下时不会往输入框里输入字符（如 Option + 空格不会输入不换行空格）。右键菜单“快速查看”旁显示当前的预览快捷键。预览打开期间焦点仍在输入框，上下方向键换行时预览跟着换，面板不会因预览窗口取得焦点而收起；关闭预览后焦点回到输入框。文件已不存在或读不到时，显示快速查看自带的提示 |
| Command + C | 复制完整路径 |
| Command + 逗号 | 设置 |
| Tab | 在名称和路径之间切换 |
| Command + 1 至 Command + 8 | 依次切换类型：不限、文件夹、文稿、图片、音频、视频、压缩包、应用程序（按数字键的物理位置，任何键盘布局都可用；筛选行显示时才生效） |
| Esc | 预览打开时先关闭预览；有输入时清空，再按一次收起 |
| 右键 | 先把灰色圆角选中底移到鼠标所指的行（不画系统的蓝色方框），再弹出菜单：打开、在访达中显示、快速查看、复制完整路径、复制名称。菜单和之后的方向键、Command + C 都作用于当前选中行 |
| 拖动结果行 | 把文件拖到别的应用 |

面板里的固定按键和文本编辑的标准按键集中定义在一张表里（`App/Sources/SearchApp/ShortcutRules.swift` 的 `PanelKeys`），冲突检查和面板的按键处理都从这张表取。类型切换的 Command + 1 至 8 也在表中，因此不能被设为自定义快捷键。表中除上面各行外，还有 Page Up/Page Down、Shift + Tab、小键盘回车，Command + A/X/V/Z、Shift + Command + Z、Command + W/M/H/Q、Option + Command + H、Command + 句号，Command 或 Option 加方向键（含加 Shift 的选择）、Option/Command + 删除键、Option + 向前删除，以及 Control + A/E/B/F/P/N/D/H/K/Y/T 这些文本编辑键。

## 5. 状态呈现

面板没有底栏（见第 3 节）。状态显示在筛选行右侧、结果数所在的位置，一次只显示一种，切换时淡入淡出：

- 正常：“1,284 个结果”。
- 首次建索引：“正在建立索引，已收录 52 万个文件”，同时可搜已收录的部分。
- 补齐云盘或外接盘：“正在补充 OneDrive，已收录 12,345 个”（数量是这一来源已收录的条目，每半秒更新；为 0 时只写“正在补充 OneDrive”）。面板筛选行里接在结果数之后（“1,284 个结果 · 正在补充 …”），菜单栏图标右键菜单的状态行、设置“索引”页的状态与之同一句话。菜单打开期间状态行也随之更新。iCloud 云盘按核心给的来源类型（`cloudProviderKind` 为 `.iCloudDrive`）显示为“iCloud 云盘”，其他云盘用核心给的名称。
- 外接盘重启后恢复上次收录的内容（核心报告该盘处于恢复阶段）时，文字改为说明这些内容已经可搜、不是从头再来：菜单状态行和“索引”页写“正在恢复 某盘 上次收录的内容，N 个已可搜索”，面板筛选行较窄，写“· 正在恢复 某盘，N 个可搜”；数量为 0 时省去数量。恢复完、开始读新内容后回到“正在补充 …”。两种阶段切换时同样淡入淡出。
- 有无法访问的位置：“有 3 个位置无法访问”，点击打开清单。

## 6. 过渡动画

| 场景 | 动画 |
|---|---|
| 面板出现 | 原地淡入约 0.14 秒，同时从 0.965 放大到 1 并上移 6，带轻微回弹；窗口本身不移动 |
| 面板收起 | 0.12 秒，淡出 |
| 列表高度变化 | 0.18 秒，缓出，不回弹 |
| 预览打开或关闭时面板左右移动 | 0.18 秒，缓出，不回弹，与列表高度变化同一手感；预览本身淡入淡出 |
| 状态文字切换 | 0.15 秒，淡入淡出 |
| 选中行变化 | 灰色圆角底在行间滑动，0.11 秒 |
| 结果刷新 | 不加动画 |
| 菜单栏图标建索引状态 | 外圈每 1.2 秒转一圈 |

系统开启“减少动态效果”时：放大和弹性全部去掉，只保留 0.1 秒淡入淡出，列表伸缩和面板左右移动直接到位，图标不旋转改为静态缺口。

## 7. 首次启动引导（设置向导）

一个固定大小（540 × 520）的窗口，五步，内容在同一位置切换，切换时约 0.15 秒淡入淡出（开启“减少动态效果”时直接切换；快速连点时上一页立即让位，不会两页叠在一起）。底部左侧“上一步”（第一步不显示），中间五个小圆点表示当前第几步，右侧是前进按钮。标题栏只有关闭按钮，随时可以关闭；关闭即表示没看到的步骤用默认值。

每一步的选择即时生效并保存，不用等到最后一步。

1. 欢迎：应用图标、“欢迎使用索隐”，说明按文件名搜索整台电脑，只读取文件名、大小和修改时间，不读文件内容，不联网。前进按钮写“开始设置”。
2. 完整磁盘访问：说明授权的好处，列出在系统设置里的操作步骤（让用户在列表里找的名字取自访达实际显示的应用名，预览版为“索隐（预览）”，与系统设置列表一致），实时检测（每秒一次）显示“尚未授权”或“已授权”，带“打开系统设置”按钮（此时回车按的是它）。下方一行淡色字说明可以先跳过以及以后在哪里开启（右键点按菜单栏图标 › 设置… › 搜索范围 › 前往授权…）。未授权时前进按钮写“暂不授权”，点了就是下一步；已授权时操作步骤和按钮隐去，前进按钮写“下一步”。
3. 外接磁盘：两个单选项，默认“不自动加入，需要时在设置里手动加入”（插入时不扫描，不额外占用磁盘和电量；想搜时在设置里打开那块盘的开关），另一个是“自动加入新插入的外接磁盘”（插上就能搜到；大容量机械硬盘首次扫描可能需要几十分钟，期间仍可正常搜索）。当前插着外接磁盘时，下方列出它们（与设置页同一种列表，最多两行高，不带删除菜单），各带“加入搜索”开关。这里和设置页读同一份数据，在一处改动另一处立即跟上。核心报告设置错误时下方显示红字（同设置页，按错误类别写中文说明并附原始信息）。
4. 快捷键与启动：“全局快捷键”录入框和“恢复默认”，与设置页同一个录入控件、同一套冲突检查和红字说明；“登录时启动”复选框，状态以系统实际登记为准。
5. 完成：写明当前实际的全局快捷键（“按 ⌥⇧空格 随时打开搜索，再按一次收起。也可以点按菜单栏中的放大镜图标。”；全局快捷键不可用时只提菜单栏图标），附几条面板里的常用按键。“开始使用”关闭向导并打开搜索面板。

何时出现：只在首次启动时自动出现一次，沿用旧版单页授权引导的标记 `accessGuideShown`，所以看过旧版引导的用户不会再被打扰；新用户不论是否已授权都会看到。之后的入口：

- 设置 › 通用 › “重新打开设置向导…”：从第一步开始。
- 菜单栏图标右键菜单的“授予完整磁盘访问权限…”（未授权时才有）、设置 › 搜索范围 › “前往授权…”：直接到第 2 步。
- 测试用启动参数：`--show-setup` 强制显示；`--demo --simulate-no-access` 在演示模式下按未授权显示（只用于看界面）。

未授权也能用，只是覆盖范围小，设置里列出无法访问的位置。

## 8. 设置

标准的 macOS 设置窗口，宽 560，顶部是带 SF Symbols 图标的工具栏式分页，窗口标题随分页变化，高度随内容变化（切换时上沿不动；会超出屏幕底部时整体上移）。每页是两列表单：左列右对齐的分组名（带全角冒号），右列系统控件，控件下方用小号次级文字说明。打开方式：菜单栏图标右键菜单的“设置…”、面板里按 Command + 逗号、应用菜单的“设置…”。窗口记住上次打开的分页。

1. 通用（齿轮）
   - 启动：“登录时启动”复选框，通过系统的登录项服务注册和注销，勾选状态始终以系统实际登记为准（窗口打开期间每秒核对一次）。操作失败时在下方用红色小字写明原因；系统要求用户批准时，显示说明和“打开登录项设置…”按钮。
   - 快捷键：两行，“全局快捷键”（默认 ⌥⇧空格，在任何地方打开或收起搜索）和“预览文件”（默认 ⌥空格，只在搜索面板里生效；说明里写明 ⌘Y 也始终可以预览、不能更改）。两行用同一个录入控件，标签、录入框、“恢复默认”按钮上下对齐；“恢复默认”只在当前不是默认值时可用。点按框进入录入状态（显示“请按下快捷键”和焦点环，按住修饰键时实时显示），按下新组合立即生效并保存，下次启动沿用；按 Esc 取消。录入任一行期间暂停全局快捷键，这样按下它也能被录入并按冲突拒绝。
   - 允许的组合：必须包含 ⌃、⌥、⌘ 中至少一个；F1 至 F12 可以不带修饰键。只有 Shift 或不带修饰键的普通键不行。
   - 冲突检查（录入时就拦住，也用于“恢复默认”）：与另一行的快捷键相同；与面板固定按键或文本编辑标准按键表中的任一项相同；与系统已启用的快捷键相同（用 `CopySymbolicHotKeys()` 读系统的符号热键表，只算已启用的，忽略功能键和方向键上的 Fn 标记，每次检查时重新读取）。冲突时在该行下方用红色小字写明组合和原因（如“⌘C：已用于“复制完整路径”，仍使用原来的快捷键。”），并保留原快捷键。预览快捷键虽是面板内的按键，与系统快捷键相同时按键到不了面板，所以同样拒绝；系统快捷键在运行期间被改得与预览快捷键相同时，设置页该行显示红字提醒。
   - 其他应用占用的组合无法事先查出：全局快捷键只有向系统登记失败时才知道（此时红字提示并保留原快捷键）；有的应用不登记、直接截取按键，这种冲突本软件发现不了。设置页的总说明压缩为三行：“点按框后按下新组合，按 Esc 取消。需含 ⌃、⌥、⌘ 之一（F1 至 F12 可单独使用），不能与另一个快捷键、面板按键或系统快捷键相同。其他应用占用的组合无法事先检测。”
   - 录入框处于“请按下快捷键”状态时，该行说明下方显示灰色小字“按下后没有反应，说明这组键已被系统占用。”（系统保留的组合根本到不了录入框）；结束录入后消失。
   - 启动自检：保存的快捷键不再合法、与固定按键相同，或两个快捷键相同（例如旧版本留下的设置）时，把后改的那个恢复默认（处于默认值的算作从未改过），在设置页对应行用次级颜色小字说明一次（如“上次设置的 ⌥空格 已用作“预览文件”，已恢复默认。”）。保存的全局快捷键已被系统或其他应用占用时同样恢复默认并说明。
   - 菜单栏图标的提示文字显示当前全局快捷键，右键菜单“快速查看”旁显示当前预览快捷键，都随设置立即更新。
   - 命令行自检：`SearchApp --self-test-shortcuts` 逐条打印“用途、组合、期望、实际、结果”后退出，全部通过时退出码为 0。
   - 程序坞：“在程序坞显示图标”复选框，默认关闭，立即生效并保存，下次启动沿用。
   - 设置向导：“重新打开设置向导…”按钮，从第一步打开首次启动时的向导。
2. 搜索范围（放大镜）
   - 显示：“显示系统文件和隐藏文件”复选框，默认开启（原则：除系统强制不让读的位置外，所有文件默认都能搜到）；说明关闭后不再显示的范围（系统目录、个人“资源库”、应用程序包内部、以“.”开头的文件），并提示微信等软件收到的文件也在其中。切换后面板里的结果立即按新设置刷新。
   - 外接磁盘：放在“显示”和“完整磁盘访问”之间。
     - 复选框“自动把新插入的外接磁盘加入搜索”，默认关闭（与设置向导第 3 步是同一个设置）。这个设置和每块盘的选择都由核心保存在它的数据目录里，界面不另存；上一版暂存在本应用偏好里的“自动加入”选择，新版首次启动时交给核心一次后删除。说明：关闭时新磁盘不会被扫描，已加入的不受影响；大容量机械硬盘首次扫描可能需要几十分钟，期间仍可正常搜索。
     - 下面是已知外接磁盘的列表，以核心给出的为准（含当前未连接但留有记录的；界面不再自己判断哪些卷算外接磁盘），带边框，每行高 40，最多显示三行，更多时在固定高度内滚动，不撑高窗口；没有任何磁盘时是一行高的空框，居中淡色字“还没有接入过外接磁盘”。
     - 每行：外接磁盘符号（未连接时变淡）、名称、次级颜色的补充说明、第二行状态，右侧“加入搜索”开关和“…”按钮。
     - 补充说明由核心给的文件系统和容量组成，如“exFAT · 1 TB”。文件系统按“磁盘工具”的叫法（apfs → APFS，hfs → Mac OS 扩展，exfat → exFAT，msdos → FAT，ntfs → NTFS，其他照原样）；容量按十进制、像包装盒上那样取整（999,962,312,704 字节写“1 TB”，63,864,569,856 字节写“64 GB”，512 GB 盘写“512 GB”；1 TB 以上不足 10 TB 时保留一位小数，如“1.5 TB”，整数时不写“.0”）。两项都没有就不显示。
     - 只从旧版文件认出、还没重新插上的盘（核心标为占位名称），名称显示为“外接磁盘 ”加上核心给的 8 位标识，如“外接磁盘 3F2A9C41”；重新插上后换成真实名称。
     - 状态文字（N 都是条目数，用等宽数字字体，随核心报告实时变化）：
       - 已加入、在线、空闲：“已加入，共 N 个文件”；可搜数为 0 而本机还保留着条目时（刚插上或刚打开开关、尚未载入）写“已加入，正在载入已收录的 N 个条目”；都没有时只写“已加入”。
       - 已加入、正在读新内容：“正在扫描，已收录 N 个”，为 0 时只写“正在扫描”。
       - 已加入、正在恢复上次收录的内容：“正在恢复上次收录的内容，N 个已可搜索”，让人看出这些内容已经能搜、不是从头再来；可搜数尚为 0 时写“正在恢复上次收录的 N 个条目”（N 为本机保留数）。
       - 未加入、在线：本机保留了条目时“未加入，保留 N 个已收录条目”，没有或尚未统计完时只写“未加入”。
       - 未连接：本机保留了条目时“未连接，保留 N 个已收录条目”，否则只写“未连接”。
       - 未加入和未连接的数量用核心给的保留数（`retainedCount`），不用可搜数（这两种情况下可搜数总是 0）；保留数尚未统计（nil）时不显示数量。
     - “…”按钮（悬停说明“更多操作”）和右键菜单有两项：“删除已收录的数据…”和“从列表中移除…”。不能用的项置灰而不隐藏（各行菜单看起来一致）；两项都不能用时按钮仍可点开，只是菜单项都是灰的。
       - “删除已收录的数据…”：保留数为 0 或尚未统计时置灰，悬停说明“这块磁盘没有已收录的数据”或“正在统计已收录的条目，稍后再试”。
       - “从列表中移除…”：只对未连接的盘可用（核心的 `canForget`）；已连接时置灰，悬停说明“磁盘连接时不能移除，请先推出磁盘”。
       - 正在移除的那一行两项都置灰，悬停说明“正在从列表中移除”，开关也暂时不能拨。
     - 从列表中移除先弹出确认（回车是“取消”，“移除”是红色的破坏性按钮）：标题“从列表中移除‘盘名’？”；本机保留了条目时说明“这块磁盘已收录的 N 个文件记录会一并删除，磁盘上的文件不受影响。以后再接入时会当作新磁盘。”，保留数为 0 时只写“以后再接入时会当作新磁盘。”，保留数尚未统计时写“这块磁盘已收录的文件记录会一并删除，磁盘上的文件不受影响。以后再接入时会当作新磁盘。”（不写数量）。按钮“移除”“取消”。
     - 确认后该行状态立即改为“正在移除…”。核心当场办完时该行随即消失；核心回报“稍后完成”（旧的跟踪还没停下）时保持“正在移除…”，核心办完发来列表变化后该行消失。失败时该行恢复原状，列表下方用红字说明（与设置错误同一行，下一次对磁盘的操作时收起）：已连接时“这块磁盘现在已连接，不能从列表中移除；请先推出磁盘再试。”；核心已没有这块盘的记录时“这块磁盘已经不在记录中，列表已刷新。”；核心暂时不能处理时“现在无法从列表中移除磁盘，请稍后再试；如果一直不行，请重新打开软件。”；保存设置或删除数据出错时按下面对应类别的说明写。
     - 设置向导第 3 步复用同一个列表控件，但只列出已连接的盘、不显示“…”按钮和右键菜单，所以没有删除和移除两项。
     - 删除先弹出确认（回车是“取消”）：写明将删除本软件为这块盘保存的 N 个已收录条目，磁盘上的文件不受影响。在线的盘写“删除后不再搜索这块磁盘，它仍留在列表中，显示为‘未加入’；以后可以重新加入，届时需要从头扫描”；未连接的盘写“这块磁盘目前未连接，删除后会从列表中移除；以后再插入时会作为新磁盘出现，加入搜索需要从头扫描”。与核心的实际行为一致：删除后在线的盘留在列表里显示“未加入”，未连接的盘从列表消失。
     - 关闭开关：不弹确认（数据还留着，随时可以再打开），停止扫描并把该盘从结果中撤下，面板里已显示的结果随即刷新；已收录的数据保留，以后打开时接着补齐。打开开关后开始扫描，列表里显示进度。开关拨动后立即显示新状态，核心处理完再以核心报告为准。
     - 核心报告设置错误（`externalVolumeSettingsError` 非空）时，列表下方用红字说明，按错误类别写成用户能懂的话，并在括号里附核心的原始信息（“（原始信息：…）”）；错误消失后这一行收起。各类别的说明：
       - 读不到设置：“读不到外接磁盘的设置，暂时按默认设置处理；这次运行期间的更改在重新打开软件后会失效。”
       - 设置文件损坏：“外接磁盘的设置文件已损坏，已改用默认设置（原文件另存了一份）；请重新选择要加入搜索的磁盘。”
       - 损坏且没能另存：“外接磁盘的设置文件已损坏，且没能另存原文件；暂时按默认设置处理，这次运行期间的更改在重新打开软件后会失效。”
       - 保存失败：“外接磁盘的设置没能保存，刚才的更改在重新打开软件后可能失效。”
       - 读不到已收录的数据：“读不到部分外接磁盘已收录的数据，这些磁盘暂时无法显示保留的条目数。”
       - 无法确认磁盘身份：“无法确认一块外接磁盘的身份，暂时没有搜索它；重新插入后会再试。”
       - 删除数据失败：“删除外接磁盘已收录的数据时出错，数据仍然保留，下次打开软件时会再试一次。”
     - 设置文件损坏时核心仍列出在线的盘（按默认设置），列表照常显示，红字说明情况。
     - 状态和数量实时更新：同样的磁盘、同样的顺序只原地更新可见行，不重载列表，所以不闪、不跳、不丢失滚动位置；磁盘增减时才重排，并保留滚动位置。
     - 测试用：`--data-dir <目录>` 让核心使用另一个数据目录；`--demo` 的演示数据覆盖正在扫描、正在恢复、未加入保留、未连接保留、占位名称几种状态；`--demo-volume-error [类别]` 显示某类设置错误（类别用核心的英文名，缺省为保存失败）；分布式通知 `dev.local.filesearch.deleteVolume`（对象为卷标识）打开删除确认，`dev.local.filesearch.quit` 以正常方式退出。
   - 完整磁盘访问：显示“已授权”或“未授权”，未授权时带“前往授权…”按钮，打开设置向导的授权一步。状态每秒核对一次。
   - 无法访问的位置：搜索范围是全盘，读不到的位置全部如实列出，系统目录也列，不隐藏。标题行显示原始位置总数（“共 341 个位置读不到”），为 0 时显示“没有无法访问的位置”并收起列表。
     - 核心尚未核对完（`inaccessibleLocationsVerified` 为假，启动、重扫、权限重查或外接盘首扫期间）时，标题行显示“正在核对…”和一个小的转动指示器，不显示任何数字；列表框保持原尺寸，框内居中一行淡色小字“核对完成后显示”。不显示上次的内容，因为其中的分组数随后可能改变。核对完成后再显示总数和清单。列表是固定高度（约 200 点）、带边框、可滚动的大纲视图，内容再多也不撑高窗口。
     - 按原因分三组，每组一个带符号的加粗小标题（含该组位置数）和一句说明（按列表实际宽度换行，说明下面紧接第一条位置，间距与其他行一致）；没有内容的组不显示。“授权后可读”（钥匙）：授予完整磁盘访问权限后就能读到。“系统权限限制”（锁）：这些位置只有系统或其他用户能读，授权后也读不到；这是 macOS 的保护，不是软件故障。“原因不明”（问号）：暂时无法判断原因。
     - 组内列核心归并后的条目：文件夹符号加路径（主目录写成“~”，中间省略，悬停显示完整路径），代表多个位置时在后面加次级文字“（含 N 个位置）”。点展开三角形列出它包含的原始位置，用相对这一条的路径显示；归并条目只代表它自己时不可展开。核心归并清单之外的原始位置单独成条，不丢弃。
     - 分组默认展开，原始明细默认收起。状态变化时实时刷新，保留已展开、已收起的分组和条目、选中行和滚动位置。
     - 列表下方说明：这些位置里的文件不会出现在搜索结果中，点三角形可看具体位置。
     - 这份清单只反映本机。有外接磁盘或云盘仍在扫描时，再下面加一行灰字，如“‘某某’仍在扫描，完成后这里可能增加。”（最多列三个名称，更多时写“‘某某’等 N 处仍在扫描……”）；没有时不显示。
   - 等待授权的位置：未授权且核心有待授权容器时才显示。说明“为了不触发系统的权限弹窗，未授权时软件不会读取其他应用的数据文件夹；授权后自动补上。”，下面是这些文件夹的列表（最多五行高，超出滚动）。
   - 选择包含哪些文件夹、排除列表：核心尚不支持，暂不提供（外接磁盘见上）。
3. 索引（硬盘）
   - 状态（与菜单里的状态行文字一致）、已收录文件数、索引占用空间（易读单位），状态变化时实时更新。已加入的外接磁盘有条目时，已收录文件数下面加一行小字“其中本机 M 个，外接磁盘 K 个”（本机含云盘）；没有外接磁盘条目时不显示。
   - “立即重建索引…”按钮：先弹出确认框（说明通常需要一到几分钟、期间仍可搜索；实测约两三分钟），确认后开始重建；建立或更新索引期间按钮不可用。

语言暂不提供单独设置，跟随系统。

## 9. 应用图标

遵守 macOS 图标网格：1024 画布中 824×824 的连续曲率圆角方形（圆角半径约 185），四周留白，带系统风格的柔和投影（向下约 10、模糊约 20、黑色约 28% 透明度）。底色暖灰近白，上亮下略深的极轻渐变，顶部边缘一道淡出的高光内描边，与搜索面板的玻璃质感呼应。

底板上是一份三行的清单（圆头横条），上下两行中性灰，中间一行系统蓝（#0A84FF）。一只深色放大镜罩在清单上：镜框和手柄为近黑的深灰，带极淡的左上亮边，手柄圆头；镜片是透明玻璃——镜片内的清单以镜片中心为原点放大约 1.16 倍并略微提亮，叠一层极淡的白色径向渐变、左上一道柔和的弧形高光和右下内沿一道细亮边；整只放大镜在底板上投下很淡的阴影。除这一处蓝色外不用其他彩色，没有文字。

16、32 像素（含 @2x 的 32、64 像素）不缩小大图，单独绘制简化版：去掉高光等细节，蓝色横条和镜框加粗，线条对齐像素格；16 像素只保留放大镜和一道蓝线，32、64 像素保留两段很短的灰条作暗示。

图标由 `App/Tools/make-icon.swift` 用 CoreGraphics 绘制生成 iconset，再用系统自带的 `iconutil` 生成 `AppIcon.icns`。目前只有一种外观：没有 Xcode 的素材编译工具，做不出随系统切换的浅色、深色、单色外观，深色模式和单色模式下都显示同一张图标。

## 10. 测试入口与开关

以下入口只为测试准备，统一受 `TestHooks.enabled`（`App/Sources/SearchApp/TestHooks.swift`）控制。开关关闭时：启动参数一律忽略，分布式通知不注册，调试日志不写。

开关规则：应用包的 Info.plist 里布尔键 `FSTestHooksEnabled` 为真，或者进程不在 `.app` 包里运行（`swift run`、直接运行 `.build/debug/SearchApp`）时打开；否则关闭。`Tools/bundle.sh` 默认打预览版，写入这个键；`Tools/bundle.sh --release` 打正式版，不写这个键，显示名为“索隐”（包标识暂时沿用，正式标识待定）。`--release` 与 `--install` 不能同时使用，以免覆盖正在使用的预览版。

启动参数：

| 参数 | 作用 |
|---|---|
| `--self-test-shortcuts` | 检查快捷键规则，逐条打印结果后退出 |
| `--demo` | 用演示数据代替真实核心 |
| `--demo-volume-error [类别]` | 演示模式下显示某类外接磁盘设置错误 |
| `--simulate-no-access` | 与 `--demo` 同用，按未授权显示 |
| `--data-dir <目录>` | 核心使用另一个数据目录 |
| `--show` | 启动后打开搜索面板，并且不自动弹出设置向导 |
| `--query <文字>` | 与 `--show` 同用，预先填入搜索词 |
| `--snapshot <路径>` | 与 `--show` 同用，把面板存成图片 |
| `--snapshot-delay <秒>` | 与 `--snapshot` 同用，存图前的等待时间，默认 1.5 秒 |
| `--pin` | 面板失去焦点或点按外部时不收起 |
| `--show-setup` | 强制打开设置向导 |
| `--appearance dark` 或 `light` | 固定本应用的浅色或深色外观 |
| `--regular` | 显示程序坞图标，便于测试工具找到窗口 |

分布式通知（名称前缀 `dev.local.filesearch.`）：

| 通知 | 作用 |
|---|---|
| `show`、`hide` | 打开、收起搜索面板 |
| `preview` | 切换快速查看，与预览快捷键相同 |
| `previewPath` | 预览指定文件（对象为路径） |
| `select` | 移动选中行（对象为 `"1"` 或 `"-1"`） |
| `deleteVolume` | 打开删除某外接磁盘数据的确认（对象为卷标识） |
| `quit` | 以正常方式退出 |

环境变量：`FILESEARCH_DEBUG_LOG=<路径>` 把搜索面板的尺寸调试信息追加写入该文件。
