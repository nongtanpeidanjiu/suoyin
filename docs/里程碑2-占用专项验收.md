## 实现取舍

- 用 `realpath(3)` 统一根目录和自有目录拼写。自动化只读验证 macOS 的 `/tmp` 别名与 `/private/tmp` 下的事件边界和排除规则。会写文件的跟踪测试在项目 `.m2-tmp/` 进行。
- 普通文件按目标路径核对。新建、删除、改名的父目录按批去重，各补一次元数据核对。首次内容观测及时应用，随后同一路径在 30 秒内合并，待办限制持久检查点。单独的 inode 元数据标志也可能表示权限等变化，走既有目录降频。目录自身事件另核对访问能力，受限或与索引矛盾时走复查。
- 匹配继续按空格分词、逐词子串匹配，保留 NFC 与英文大小写规则。仅 NFC 结果改变的非 ASCII 名称保存折叠键。ASCII 大小写在查询和排序中即时折叠，池扫描使用 NEON 筛选候选。
- 增量日志格式、索引记录结构和合并流程沿用现有实现。全盘只用常规文件元数据接口，扫描最多 4 个线程。报告中的查询回放、慢参照和全盘监听均串行运行。

建议下一轮先定位 FSEvents 在有效热重放后出现 `UserDropped` 的条件，复测时记录回调批次大小和交付时延，再按相同口径跑一个连续有效的 900 秒窗口。

### 残留索引修正

合并会为缺少已索引父项的编辑建立独立绝对路径锚点。部分锚点身处 Data 卷范围，却没有可沿父链追溯的 Data 根，导致恢复时被误当作封闭系统卷数据保留。修正后在提取封闭卷时也按锚点的绝对路径排除 Data 范围。最终版本还将退出时最后一批监听回调纳入检查点处理。

随后用最终构建重新打开同一基准和日志。启动检查到失效位置后恢复 Data 卷。旧视图在扫描期间仍可查询。切换后，已删除压力树的路径查询返回 0 行，五个树外样本的路径、大小和修改时间与 `lstat` 一致。恢复耗时 13.518 秒，进程物理占用最高 252.94 MB，追平后为 123.93 MB。既有 24 小时额度已用完，整档写入和进程写入均为 0，状态已追平且退出成功。此定向复核沿用压力试验的基准，没有再次创建压力文件。它覆盖残留索引修正和恢复内存目标，压力窗口的终态和五分钟资源判定仍见上表。

### 后续验收口径

- 同一份快照、相同预热和测量长度，至少保留 180 秒的真实全盘监听数据。两个边界记录用户态和系统态 CPU 秒、墙钟、FSEvents 收件、实际应用批、直接文件和目录核验、云完成、失败与待办，另记外接卷登记数和加入数。报告物理峰值、进程写盘量及基准整档重写次数。
- CPU 和内存用进程外 `proc_pid_rusage` 采集，或仅在首尾读取被测进程的 CPU 和状态计数。避免在被测窗口内高频调用包含 `malloc_zone_statistics` 的 `ChangeTracker.processMetrics()`。需要采集堆统计时单独开诊断窗口。
- 无事件基础另用固定的零收件、零云任务窗口记录；有一条注入的未加入登记和无登记各做一个 180 秒对照。自然全盘若仍有后台活动，公布其数据并说明未取得零收件的全盘窗。每千个事件用扣除基础后的 CPU 秒计算，同时给出应用批与云任务数。没有事件时该开销不适用，有云任务时注明它混在剩余成本中。

首次复跑发现既有云盘用例收到补齐通知后可能早于本机核验状态发布。该用例现在等待同一个状态快照同时报告本机已核验、云来源仍在补齐，然后释放注入的目录任务。

### 实现与一致性

| 调整 | 可能遗漏的条件 | 兜底和成本 |
|---|---|---|
| 同批父目录已列出准确名称时，合并结构事件对一个已消失、拼写已作废或已换成文件的子目录的复核 | 父目录读完后子目录重新出现，或者权限、占位状态使父目录结果无法确认 | 父目录未成功列出、目标子项有拒绝记录、或工作同时要求独立递归时，仍核对子目录。读完后发生的变化走后续事件，检查点遵守已处理事件边界。该捷径只减少无效的子目录探测，成功枚举的保留成本见固定回放。 |
| 按覆盖层父目录关系清理受影响的子树 | 持久化覆盖记录的中间目录缺行，或覆盖记录插入后未建立父级链接 | 载入覆盖层时按每条路径重建父级链接，中间目录无需有搜索行。增删统一维护链接，原有基准子树和权限清理照常执行。成本随受影响的基准后代、覆盖层分支及记录增长。 |
