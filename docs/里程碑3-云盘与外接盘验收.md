# 里程碑 3 云盘与外接盘验收

2026-11-18，Apple M2、8 GiB、macOS 15.7.9、Command Line Tools Swift 6.1.2。基于 `173375d`。MB 按十进制计。原始含路径记录留在本机忽略目录 `.m2-tmp/task10/`。

## 外接盘

四卷实机方案在磁盘映像准备阶段受阻。APFS 稀疏映像能创建，512 MiB GPT 映像以 `-nomount` 可见 APFS 分区和合成卷。正常挂载和指定项目挂载点均返回“无可装载的文件系统”或“卷挂载失败”。exFAT 稀疏映像创建返回“操作不被允许”。停止映像尝试，已分离诊断设备并删除本轮创建的映像与临时挂载目录。

| 项目 | 证据 | 判定 |
|---|---|---|
| APFS、exFAT 真实挂载自动发现 | 映像准备受阻 | 未完成实机验收 |
| APFS 新建、改名和删除后 2 秒内反映 | 无已挂载测试卷 | 未测 |
| exFAT 目录复查、慢速标记 | 模拟目录级卷核对慢速状态。缺少可用文件级位置的卷设 600 秒复查 | 未测实机事件和延迟 |
| UUID 及日志 UUID、换挂载点重放 | 自动化核对身份、过期事件位置、锚点重定位和历史重放 | 自动化覆盖 |
| 两个同名卷相互独立、拔出隐藏、无 UUID 重插重扫 | 注入独立实例核对挂载、撤下和再扫描 | 自动化覆盖。实机事件位置独立性及卸载延迟未测 |

## 实现取舍

- 可搜内容与待补位共用现有索引格式和变化日志。云后台只读取目录清单及条目元数据。待补队列重启后从索引恢复。逻辑超时使结果失效，系统调用占用的单槽保留到实际返回。
- 外接卷按独立索引和事件流处理。历史缓存按卷 UUID 和日志 UUID 共同定位。挂载点变化时重定位现有路径。卸载先撤下视图，再停止工作。程序的外接卷状态提供慢速标记以及独立事件位置。
- 外接卷扫描只读。其监听先启动，持久位置取扫描前可证位置和后续实际应用的事件，无须在外盘写标记。外接盘和本机、云盘共用四个目录读取槽。

## 回归与资源

第一次注入和资源窗口采用 200 ms 间隔的构建。一次注入使主卷进入待恢复，重建用时 14.668 秒并回到已追平。随后连续 300.003 秒平均单核 1.113%，最高物理占用 134.547 MB，整档写入、整卷恢复和进程新增写盘均为 0。云盘在该窗口完成 236 个目录，末次仍有 270 个目录待补。末次可搜 2,156,501 条，物理占用 133.105 MB。CPU 项未通过。该构建在注入待恢复阶段的拒绝应用计入了 10 次失败，实机云盘初段失败为 0。后续构建在进入待恢复时暂停补齐并作废在途结果，避免计作提供商失败。

为降低补齐持续期间的单核占用，后续构建将目录读取间隔从 200 ms 调至 700 ms，将增量覆盖的分区数从 8 调至 16，缩小每次发布对已准备索引的重建范围。

## 验收结论

查询、常规五分钟全盘监听、自有目录回归和自动化达标。云盘在真实范围内持续发布文件名，测量结束时队列仍有 239 个目录，整批补齐总耗时和队列清空后的稳态未取得。外接卷的实现及模拟回归已完成，APFS、exFAT 和同名映像的真实挂载、事件延迟及卸载仍待实机验收。建议继续观察可用云根至待补清零，并在可挂载自有映像的会话补跑四卷矩阵。

本机证据位于 `.m2-tmp/task10/`。使用 `pressure/transcript.jsonl` 复算里程碑 2 自然窗口，`final-live/summary.json` 核对注入与第一轮资源值，`ordinary-live/summary.json` 核对常规五分钟，`regression/functional.json` 核对自有目录，`query-final/` 核对最终查询和测试。
