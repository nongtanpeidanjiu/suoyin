# 界面规格 v5.0

状态：已获用户同意的设计方向（2026-11-18）。界面层由统筹方实现，搜索核心不负责界面。

## 1. 设计原则

- 用系统自带的东西：系统字体、SF Symbols、系统强调色、毛玻璃材质、真实文件图标。自动跟随浅色和深色模式。
- 只用一种强调色（系统强调色）。不用渐变、发光、彩色光晕、星形装饰。
- 输入即出结果的手感优先于一切动画：与按键直接相关的反馈不加动画。
- 尊重系统辅助功能设置：减少动态效果、增强对比度、读屏（每个控件有无障碍标签）。
- 所有界面文字走本地化表，首批中文和英文。

## 2. 入口

| 入口 | 行为 |
|---|---|
| 菜单栏图标左键 | 切换搜索面板的显示和隐藏 |
| 菜单栏图标右键或按住 Control 点击 | 弹出菜单：打开搜索、索引状态、无法访问的位置、设置、退出 |
| 全局快捷键（默认 Option + Shift + 空格，可改） | 与左键相同 |
| 程序坞 | 默认不显示图标（常驻菜单栏类应用），设置里可改 |

菜单栏图标是单色模板图，随菜单栏深浅自动变色。三种状态：平时（放大镜内两条短线）、建索引中（外圈缺口缓慢旋转）、需要处理（放大镜内感叹号）。

## 3. 搜索面板

设计参照：苹果在 macOS 26 中重新设计的系统搜索（聚焦搜索）。本软件不照搬其功能，只沿用它的形态语言。

形态：一块明亮通透的玻璃，跟随系统的浅色和深色模式。宽 640。

- 静止时是一枚胶囊：只有一行搜索框，高 54，两端是完整的半圆（圆角 27）。
- 开始输入后，同一块玻璃向下生长，依次出现筛选行和结果列表；圆角保持 27，搜索行本身不移动。
- 面板出现在当前屏幕水平居中、搜索行位于屏幕高度约三分之一处。屏幕较矮时整体上移，保证完整列表放得下。
- 失去焦点或按 Esc 时收起。可以拖动。
- 玻璃上覆一层很淡的白（深色模式为淡黑），边缘有一条亮的细线作为玻璃的高光；使用系统窗口阴影。

结构自上而下：

1. 搜索行（高 54）：放大镜符号、输入框（23 号字，占位文字“搜索文件”）。
2. 筛选行（高 34）：左侧是胶囊形筛选按钮“名称”“路径”，当前项底色略深；右侧用很淡的小字显示结果数量或索引状态。点击或按 Tab 切换。以后的类型筛选（文件夹、图片、文稿等）也放在这一行。
3. 结果列表：每行高 46。左侧真实文件图标（30），第一行文件名（14 号，匹配部分只加粗、不变色），第二行所在位置（11.5 号，次级颜色，用“›”分隔），右侧修改时间（今天显示时刻，今年显示月日，更早显示完整日期）。云端未下载的文件名后加云朵符号，外接盘上的加外接盘符号。
4. 选中行：一块圆角的半透明灰色底，不使用强调色，文字颜色不变。整个面板的颜色只来自文件图标。
5. 没有底栏。快捷键说明放在设置和首次引导里。

尺寸变化：最多显示 7 行半（露出半行提示可以滚动），不足按实际行数。没有结果时显示一行“没有找到匹配的文件”。

## 4. 键盘和鼠标

| 操作 | 结果 |
|---|---|
| 上下方向键 | 移动选中行，焦点仍在输入框 |
| 回车或双击 | 打开文件 |
| Command + 回车 | 在访达中显示 |
| 空格（输入框为空或已选中行且按住 Option 时不作为输入） | 快速查看预览 |
| Command + C | 复制完整路径 |
| Command + 逗号 | 设置 |
| Tab | 在名称和路径之间切换 |
| Esc | 有输入时清空，再按一次收起 |
| 右键 | 菜单：打开、在访达中显示、复制完整路径、复制名称 |
| 拖动结果行 | 把文件拖到别的应用 |

## 5. 状态呈现

底栏左侧一次只显示一种状态，切换时淡入淡出：

- 正常：“1,284 个结果”。
- 首次建索引：“正在建立索引，已收录 52 万个文件”，同时可搜已收录的部分。
- 补齐云盘或外接盘：“正在补充 OneDrive 的文件”。
- 有无法访问的位置：“有 3 个位置无法访问”，点击打开清单。

## 6. 过渡动画

| 场景 | 动画 |
|---|---|
| 面板出现 | 原地淡入约 0.14 秒，同时从 0.965 放大到 1 并上移 6，带轻微回弹；窗口本身不移动 |
| 面板收起 | 0.12 秒，淡出 |
| 列表高度变化 | 0.18 秒，缓出，不回弹 |
| 状态文字切换 | 0.15 秒，淡入淡出 |
| 选中行变化 | 灰色圆角底在行间滑动，0.11 秒 |
| 结果刷新 | 不加动画 |
| 菜单栏图标建索引状态 | 外圈每 1.2 秒转一圈 |

系统开启“减少动态效果”时：放大和弹性全部去掉，只保留 0.1 秒淡入淡出，图标不旋转改为静态缺口。

## 7. 首次启动引导

三步，可随时“暂不授权”：欢迎和说明（只读取文件名，不读内容，不联网）、授予完整磁盘访问（带打开系统设置的按钮和实时检测）、选择快捷键和是否登录时启动。未授权也能用，只是覆盖范围小，底栏提示无法访问的位置。

## 8. 设置

三个分页：通用（登录时启动、快捷键、程序坞图标、语言）、搜索范围（包含哪些卷和文件夹、是否显示系统文件、排除列表）、索引（状态、文件数量、占用空间、立即重建）。

## 9. 应用图标

圆角方形，暖灰底。一份三行的清单，中间一行是系统蓝色，一只深色放大镜罩在清单上。除这一处蓝色外不用其他彩色。提供浅色、深色、单色三种外观。
