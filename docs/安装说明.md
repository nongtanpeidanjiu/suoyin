# 安装说明

这份说明写给第一次安装索隐的人，不需要技术背景。

需要： Apple 芯片（M1 及以后）的 Mac，macOS 15.7.9 或更高版本。查看方法：点屏幕左上角的苹果图标 › “关于本机”。

下文引号里的按钮和标题按 macOS 15 的界面写；不同系统版本的措辞可能略有差别，以实际显示为准。

---

## 第一步：下载，拖进“应用程序”

1. 打开[发布页](https://github.com/nongtanpeidanjiu/suoyin/releases/latest)，在“Assets”下面点以 `.dmg` 结尾的安装包下载（文件名形如 `Suoyin-版本号.dmg`，以发布页为准）。
2. 在“下载”文件夹里双击这个安装包，会打开一个窗口，里面有“索隐”和“应用程序”两个图标。
3. 把“索隐”拖到窗口里的“应用程序”图标上。
4. 拷贝完成后，在访达侧边栏点安装包名字旁边的推出按钮，再把下载的安装包扔进废纸篓（可选）。

![把索隐拖进“应用程序”文件夹](images/install-1.png)

## 第二步：首次打开被拦时，去“隐私与安全性”放行

在“应用程序”里双击“索隐”。第一次打开时，系统会弹出类似“未打开‘索隐’”的提示，只有“完成”和“移到废纸篓”两个按钮（以实际显示为准）。点“完成”，不要点“移到废纸篓”。

![系统拦下索隐时的提示](images/install-2.png)

然后：

1. 打开“系统设置”（苹果图标 › “系统设置…”），在左侧点“隐私与安全性”。
2. 在右侧往下滚动到“安全性”一节，会看到一行类似“已阻止‘索隐’以保护 Mac”的文字（以实际显示为准），旁边有 “仍要打开” 按钮，点它。
3. 系统再次确认时，点“仍要打开”，按要求输入开机密码或用触控 ID 验证。

![在“隐私与安全性”里点“仍要打开”](images/install-3.png)

放行只需要做这一次，以后直接打开即可。

> 提示：这一行只在你尝试打开之后的一段时间内出现。如果没看到，先回到“应用程序”再双击一次“索隐”，然后马上回到“隐私与安全性”查看。

### 为什么会被拦？

苹果要求开发者每年付费注册开发者账号，再把软件提交给苹果“公证”，系统才会直接放行。我没有购买苹果开发者账号，所以索隐没有经过公证。对于所有没经过公证的软件，系统都会这样拦一次。这不代表软件有问题，只是说明苹果没有替你检查过它。

如果你想自己确认拿到的文件就是我发布的那一份，见下面的“核对下载的文件”。

## 第三步：授予“完整磁盘访问权限”

索隐打开后会出现设置向导。到第二步“让搜索覆盖整台电脑”时：

1. 点向导里的 “打开系统设置”，系统设置会打开“隐私与安全性”。
2. 找到并点开 “完整磁盘访问权限”。
3. 在列表里找到“索隐”，打开它右边的开关。列表里没有时，点下方的“＋”，从“应用程序”里选“索隐”添加。
4. 系统可能提示需要退出并重新打开索隐才能生效，按提示操作即可（以实际显示为准）。

![在“完整磁盘访问权限”里打开索隐的开关](images/install-4.png)

回到向导，状态会在一秒内变成“已授权”。

这一步可以跳过。 不授权也能搜，只是邮件、信息等受系统保护的位置搜不到。以后想开启：右键点按菜单栏里的索隐图标 › “设置…” › “搜索范围” › “前往授权…”。

索隐拿这个权限做什么、不做什么，见 [README 的说明](../README.md#完整磁盘访问权限)和[隐私说明](../PRIVACY.md)。

## 开始使用

向导最后一步写着当前的快捷键。默认按 Option + Shift + 空格 打开搜索，输入文件名，回车打开。也可以点菜单栏里的放大镜图标。

首次启动后索隐会先建立索引，期间就可以搜索已收录的部分；在我的测试机上，约 193 万个条目用了约 18 秒（实测条件见 [README](../README.md#实测条件)）。

## 核对下载的文件

安装包： 每个版本的发布页都会写明安装包的 SHA-256 校验和。下载后打开“终端”（在“应用程序 › 实用工具”里），输入下面的命令（把路径换成你实际下载的文件，可以直接把文件拖进终端窗口代替手打路径）：

```sh
shasum -a 256 ~/Downloads/安装包文件名
```

终端打印出的一长串字母数字，和发布页上写的完全一致，就说明文件和我发布的一模一样，下载过程中没有被改动。不一致就不要打开，删掉重新下载。

已安装的应用： 下面的命令检查应用自带的签名是否完好，即应用里的文件在签名之后有没有被改动过：

```sh
codesign --verify --deep --strict /Applications/索隐.app && echo 签名完好
```

自动更新： 索隐的自动更新（基于开源组件 Sparkle）只接受带我签名的更新包：应用里内置了我的公钥，下载的更新包签名对不上就不安装，不需要你手动核对。

## 如何彻底卸载

1. 退出索隐： 右键点按菜单栏里的索隐图标 › “退出”。
2. 删除应用： 在“应用程序”文件夹里把“索隐”拖进废纸篓。
3. 删除索引数据： 在访达里按 Shift + Command + G（“前往文件夹”），输入下面的路径，把整个文件夹拖进废纸篓：

   ```
   ~/Library/Application Support/io.github.nongtanpeidanjiu.suoyin
   ```

   这个文件夹里是全盘文件名的索引和其他磁盘的设置，删除后磁盘空间随即释放。

4. 删除缓存： 同样用“前往文件夹”打开下面的路径，删除这个文件夹（如果存在）。里面是预览的临时副本和自动更新下载的更新包：

   ```
   ~/Library/Caches/io.github.nongtanpeidanjiu.suoyin
   ```

5. 删除偏好设置： 打开“终端”，输入：

   ```sh
   defaults delete io.github.nongtanpeidanjiu.suoyin
   ```

   这会删除快捷键、“显示系统文件”开关、更新方式等设置。提示“does not exist”说明本来就没有，可以忽略。

6. 在系统设置里移除授权：
   - “系统设置 › 隐私与安全性 › 完整磁盘访问权限”：选中“索隐”，点下方的“－”。
   - “系统设置 › 通用 › 登录项”：如果“登录时打开”里还有“索隐”，选中后点“－”（以实际显示为准）。

7. 最后清倒废纸篓。

> 第 3、4、5 步中的 `io.github.nongtanpeidanjiu.suoyin` 是正式版的应用标识。如果你用的是自己编译的预览版（显示为“索隐（预览）”），应用标识是 `dev.local.filesearch.demo`：第 3 步的索引数据文件夹改为 `~/Library/Application Support/dev.local.filesearch`，第 4、5 步的标识换成 `dev.local.filesearch.demo`；预览版默认装在个人文件夹的“应用程序”里，名为“文件搜索预览”。两种版本的数据互不相干，都装过的话两套都要删。
