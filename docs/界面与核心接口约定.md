# 界面与核心接口约定 v0.1

目的：界面层（`App/`）和搜索核心（`Sources/SearchCore`）各自开发，只通过本文件定义的接口往来。界面先用假实现开发，核心通过验收后由 Codex 提供真实实现。

本版是草案，核心返工通过后再核对一次定稿。

## 1. 约束

- 界面只依赖下面的协议，不直接使用 `ChangeTracker`、`LiveIndex` 等内部类型。
- 查询不得阻塞主线程。界面在后台队列调用 `search`，用请求编号丢弃过期结果。
- 核心的状态变化通过回调通知，回调可以在任意线程触发，界面负责切回主线程。
- 核心不弹窗、不读写界面偏好；界面不直接读写索引文件。

## 2. 数据类型

```swift
public enum SearchScope { case name, path }
public enum SortColumn { case name, location, size, modified }
public enum SortOrder { case ascending, descending }

public struct SearchRequest {
    public var text: String
    public var scope: SearchScope
    public var sort: SortColumn
    public var order: SortOrder
    public var includeSystemFiles: Bool
    public var offset: Int
    public var limit: Int
}

public struct SearchHit {
    public var id: UInt64          // 同一次索引状态内稳定，用于保持选中行
    public var name: String
    public var path: String        // 完整路径
    public var isDirectory: Bool
    public var size: Int64
    public var modified: Date
    public var isCloudPlaceholder: Bool   // 在云端，未下载
    public var isOnExternalVolume: Bool
}

public struct SearchResponse {
    public var hits: [SearchHit]
    public var total: Int          // 匹配总数；核心给不出精确值时给下限并置 totalIsExact 为 false
    public var totalIsExact: Bool
}

public enum IndexPhase {
    case starting
    case scanning(indexed: Int)            // 首次建库，已收录数量
    case ready
    case supplementing(volumeName: String) // 后台补齐云盘或外接盘
    case degraded(reason: String)
}

public struct IndexStatus {
    public var phase: IndexPhase
    public var indexedCount: Int
    public var inaccessiblePaths: [String]
    public var indexBytesOnDisk: Int64
}
```

## 3. 服务协议

```swift
public protocol SearchService: AnyObject {
    func start()
    func stop()
    func search(_ request: SearchRequest) -> SearchResponse   // 同步，线程安全，目标第 95 百分位 20 毫秒内
    var status: IndexStatus { get }
    var onStatusChange: ((IndexStatus) -> Void)? { get set }
    var onIndexChange: (() -> Void)? { get set }              // 索引内容变了，界面可重新查询当前输入；核心自行节流，不超过每秒 4 次
    func recheckAccess()                                       // 用户改了授权后调用
    func rebuild()
}
```

## 4. 待与核心核对的事项

1. 现有 `SearchRow` 没有“是否文件夹、是否云端占位、是否外接盘”三个标志，需要核心补出。
2. 匹配总数：现有接口只返回一页结果，需要补一个便宜的计数，或允许返回下限。
3. `id` 目前是 32 位行号且覆盖层带高位标记，重建或合并后会变；界面只在两次 `onIndexChange` 之间依赖它。
4. 高亮范围由界面按与核心相同的规则（空格分词、不分大小写、NFC）自行计算，规则变更时两边同步。
