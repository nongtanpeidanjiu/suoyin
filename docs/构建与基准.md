# 里程碑 1 构建与基准

在仓库根目录使用 macOS 15.7.9 或以上的 Apple Silicon Mac、Command Line Tools、SwiftPM 与 Python 3.9+。先依次构建和测试。

```sh
swift build -c release -j 4
swift test -c release -j 4 --disable-xctest --enable-swift-testing
mkdir -p .m1-tmp/repro
cli=.build/release/file-search
run=.m1-tmp/repro
research='.flow/tasks/20261118-Mac文件名搜索技术预研/evidence/all.bin'
```

复现真实预研语料及合成百万命中回放。命令逐个运行。原始文件名称和生成的快照留在本机忽略目录。

```sh
python3 scripts/measure.py "$run/import.jsonl" "$run/monitor.jsonl" "$cli" import "$research" "$run/real.snapshot"
python3 scripts/measure.py "$run/synthetic.jsonl" "$run/monitor.jsonl" "$cli" synthetic 2127824 "$run/million.snapshot"
python3 scripts/requests.py real "$run/real-queries.json"
python3 scripts/requests.py million "$run/million-queries.json"
python3 scripts/measure.py "$run/real.jsonl" "$run/monitor.jsonl" "$cli" replay "$run/real.snapshot" "$run/real-queries.json" 30
python3 scripts/measure.py "$run/million.jsonl" "$run/monitor.jsonl" "$cli" replay "$run/million.snapshot" "$run/million-queries.json" 30
python3 scripts/measure.py "$run/real-check.json" "$run/monitor.jsonl" python3 scripts/oracle.py "$run/real.snapshot" "$run/real-queries.json" "$run/real.jsonl"
python3 scripts/measure.py "$run/million-check.json" "$run/monitor.jsonl" python3 scripts/oracle.py "$run/million.snapshot" "$run/million-queries.json" "$run/million.jsonl"
python3 scripts/startup.py "$cli" "$run/real.snapshot" > "$run/startup.jsonl"
python3 scripts/recovery.py "$cli" "$run" > "$run/recovery.jsonl"
```

全盘实机复现从监听、部分首屏到本机全部可搜。可将 `/` 换成自有测试目录，补 `--ordinary` 强制普通枚举对照。运行全盘时，保留已知占位样本的前后元数据。测量守护以约 100 毫秒间隔监测当前测量进程 RSS，超 1.5 GB 或监测明显停顿时终止。发生系统级错误停止后续命令并保留日志。

```sh
placeholders='.flow/tasks/20261118-Mac文件名搜索技术预研/evidence/超时后占位复核.json'
python3 scripts/placeholders.py "$placeholders" > "$run/placeholders-before.json"
python3 scripts/measure.py "$run/scan.jsonl" "$run/monitor.jsonl" "$cli" scan / "$run/live.snapshot" "$run/partial.snapshot" "$run/local.snapshot"
python3 scripts/placeholders.py "$placeholders" > "$run/placeholders-after.json"
cmp "$run/placeholders-before.json" "$run/placeholders-after.json"
python3 scripts/measure.py "$run/partial-check.json" "$run/monitor.jsonl" python3 scripts/oracle.py "$run/partial.snapshot" "$run/real-queries.json" "$run/scan.jsonl" --phase partial
python3 scripts/measure.py "$run/local-check.json" "$run/monitor.jsonl" python3 scripts/oracle.py "$run/local.snapshot" "$run/real-queries.json" "$run/scan.jsonl" --phase local_complete
python3 scripts/measure.py "$run/scan-audit.json" "$run/monitor.jsonl" python3 scripts/scan_audit.py "$run/live.snapshot"
python3 scripts/measure.py "$run/roundtrip.jsonl" "$run/monitor.jsonl" "$cli" roundtrip "$run/live.snapshot" "$run/copy.snapshot"
cmp "$run/live.snapshot" "$run/copy.snapshot"
```

调用核心库时，从 `SearchIndex.scan` 接收可搜索批次，也可从 `SearchIndex.load` 读取保存的快照。在完整视图上调用 `prepare()` 预建匹配和排序结构，再以 `search` 查询或分页。`directSearch` 可用于正在分批发布的视图和对照测量。CLI `replay ... --direct` 执行保留的直接实现。扫描监听只覆盖本次扫描过程，事件重放与增量应用由下一里程碑实现。
